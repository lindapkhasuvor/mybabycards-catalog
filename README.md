# MyBabyCards Catalog

Каталог MyBabyCards для GitHub Pages.

- 🗣️ Говорилки — 80
- 👶 Первые слова — 49
- 😊 Эмоции — 17

Карточки остаются в Dropbox. На сайте используется официальный Dropbox Embedder.

## Подключение Dropbox App

Создайте Dropbox App для Embedder и вставьте только App Key в `config.js`.
Не публикуйте App Secret или access token в репозитории.

## GitHub Pages

В репозитории откройте Settings → Pages → Source: Deploy from a branch → Branch: main → Folder: /(root) → Save.

GitHub Pages публикует `index.html` из выбранного источника.
